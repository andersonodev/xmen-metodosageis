# 👥 Perfis de Usuário - X-Men AgileTeam

## Hierarquia de Usuários

### 🔧 Admin
- **Descrição**: Administrador do sistema com acesso completo
- **Permissões**: Acesso a tudo no sistema
- **Funcionalidades**:
  - Gerenciar todos os usuários
  - Acessar todas as equipes e projetos
  - Configurações do sistema
  - Relatórios gerais
  - Backup e manutenção

---

## 👤 Perfil de Líder

O líder possui um perfil próprio e acesso a uma página exclusiva de gerenciamento de equipes.

### 🎯 Funcionalidades Principais

#### 1. Criação e Configuração de Equipes
- ✅ Criar equipes ágeis com 3 a 7 integrantes
- ✅ Definir nome, descrição e objetivos da equipe
- ✅ Configurar metodologia ágil (Scrum, Kanban, etc.)
- ✅ Estabelecer cronograma e metas

#### 2. Seleção de Categorias de Projeto
- 📋 Escolher prompts conforme tipo de demanda:
  - **Desenvolvimento Web**: Frontend, Backend, Full-stack
  - **Mobile**: iOS, Android, React Native, Flutter
  - **Data Science**: Análise de dados, Machine Learning, BI
  - **DevOps**: CI/CD, Cloud, Infraestrutura
  - **Design**: UX/UI, Branding, Marketing Visual
  - **Marketing**: Digital, Conteúdo, SEO, Social Media

#### 3. Geração Automática de Equipes
- 🤖 Sistema inteligente baseado em:
  - Categorias selecionadas
  - Tamanho da equipe definido
  - Habilidades complementares
  - Disponibilidade dos colaboradores
  - Histórico de performance

#### 4. Visualização de Integrantes
- 👥 Informações detalhadas de cada membro:
  - **Nome completo** e foto de perfil
  - **Função/Cargo** na equipe
  - **Habilidades técnicas** e nível
  - **Experiência** em projetos similares
  - **Disponibilidade** atual

#### 5. Gerenciamento de Projetos
- 📊 Painel de controle com:
  - **Projetos ativos** da liderança
  - **Status** de cada equipe em tempo real
  - **Métricas** de performance
  - **Timeline** e marcos importantes
  - **Riscos** e impedimentos

### 🔑 Permissões Especiais
- Criar e editar equipes
- Atribuir e remover colaboradores
- Definir papéis e responsabilidades
- Acessar relatórios de performance
- Aprovar entregas de sprints

## 👥 Perfil de Colaborador

O colaborador possui um perfil individual completo para gestão de sua participação em projetos.

### 📋 Informações do Perfil

#### 1. Dados Pessoais
- 📸 **Foto de perfil** personalizada
- 👤 **Nome completo** e informações de contato
- 🏢 **Departamento** e cargo atual
- 📧 **Email** e meios de comunicação

#### 2. Habilidades Ágeis
- 💻 **Competências técnicas**:
  - Linguagens de programação
  - Frameworks e ferramentas
  - Tecnologias cloud
  - Metodologias ágeis
- 📊 **Níveis de proficiência**:
  - Iniciante (1-2 anos)
  - Intermediário (3-5 anos)
  - Avançado (5+ anos)
  - Especialista (referência)

#### 3. Histórico de Projetos
- 📈 **Painel de projetos** com:
  - Projetos concluídos
  - Projetos em andamento
  - Projetos futuros/planejados
  - Avaliações recebidas

#### 4. Detalhes dos Projetos
- 🔍 **Visualização completa** incluindo:
  - **Equipe** completa do projeto
  - **Líder responsável** e contato
  - **Objetivos principais** e entregáveis
  - **Timeline** e marcos
  - **Tecnologias** utilizadas

### 🎯 Funcionalidades Disponíveis
- Atualizar perfil e habilidades
- Visualizar designações atuais
- Acompanhar progresso de projetos
- Comunicar com a equipe
- Reportar impedimentos

## 🏠 Página Inicial do Colaborador

Dashboard personalizado com visão geral das atividades.

### 📊 Seções da Dashboard

#### 1. Projetos Ativos
- 🚀 **Lista dinâmica** com:
  - Nome do projeto
  - Status atual (Em andamento, Pausado, etc.)
  - Progresso percentual
  - Próximas entregas

#### 2. Equipes Participantes
- 👥 **Cards de equipes** mostrando:
  - Nome da equipe
  - Líder responsável
  - Outros membros
  - Função no projeto

#### 3. Status e Resumos
- 📈 **Indicadores** como:
  - ✅ **Concluído**: Projetos finalizados
  - 🔄 **Em andamento**: Atividades atuais
  - ⏳ **Aguardando início**: Próximos projetos
  - ⚠️ **Atrasado**: Itens com delay

#### 4. Próximas Atividades
- 📅 **Agenda** com:
  - Reuniões marcadas
  - Deadlines importantes
  - Reviews de código
  - Apresentações

## 🚀 Jornada do Usuário

### Para Líderes:
1. **Login** → Dashboard de liderança
2. **Criar projeto** → Definir requisitos
3. **Gerar equipe** → IA sugere membros
4. **Aprovar equipe** → Notificar membros
5. **Acompanhar progresso** → Dashboards em tempo real

### Para Colaboradores:
1. **Login** → Dashboard pessoal
2. **Visualizar projetos** → Status atuais
3. **Atualizar perfil** → Habilidades e disponibilidade
4. **Participar de equipes** → Contribuir para projetos
5. **Receber feedback** → Crescimento contínuo
